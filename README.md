## What I do

Four weeks from first call to a result you can defend in a board meeting. No retainer, no
discovery theatre.

**01 · Exploratory Sprint — 5 days.** I trace your funnel end to end and find where work
leaks. You leave with a written hypothesis, the assumptions it rests on, and the boundaries
we agree not to cross.

**02 · Measured Experiment — 3 weeks.** The number gets agreed before the first line of
code. We build against a single measurable outcome — pipeline influenced — and the
guardrails are documented up front, not patched in after something breaks.

**03 · The verdict.** It moved the number, or it did not. Both are results. Most agent
pilots never reach this point because nobody agreed what success looked like on day one.
