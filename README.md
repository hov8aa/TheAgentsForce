# The Agents Force — theagentsforce.com

Static site for [theagentsforce.com](https://theagentsforce.com), hosted on GitHub Pages.

No frameworks, no CDNs, no third-party requests. Every byte the visitor loads is served
from this repo.

---

## Deploying

Push the contents of this folder to the root of `main`. In the repo's
**Settings → Pages**, set the source to **Deploy from a branch → main → / (root)**.

`CNAME` and `.nojekyll` are already here and both need to stay.

---

## Editing the site

Everything you'd normally want to change lives at the top of `build.py`, in the
section marked `CONTENT`:

| What you want to change | Where |
|---|---|
| Hero headline and subhead | `HERO` |
| The three agent cards | `AGENTS` |
| Sprint steps, price | `PROCESS` |
| About copy and the three facts | `ABOUT` |
| Journal posts on `journal.html` | `POSTS` |
| Calendar / LinkedIn / X / YouTube links | `LINKS` |

Then run:

```
python3 build.py
```

That regenerates `index.html`, `journal.html`, `journal-agent-001.html`, `404.html`,
`sitemap.xml` and `robots.txt`. Commit the result.

Design tokens (colours, type scale, spacing, shadows) live at the top of `styles.css`.
That file is hand-maintained — `build.py` never touches it.

### Adding a journal post

1. Add an entry to `POSTS` in `build.py`.
2. Add a `page_*()` function for the article, following `page_article()` as the model.
3. Register it in `main()` and in the `urls` list that builds the sitemap.
4. Run `python3 build.py`.

## Performance

A first visit to the homepage is **~135 KB across 8 requests**, all first-party.
The HTML contains the full page text, so social crawlers and search engines see the
content without running any JavaScript.

## Accessibility

- Every colour pair in the palette clears WCAG AA (lowest is 5.5:1).
- Visible keyboard focus on all interactive elements.
- Skip-to-content link, landmark elements, one `<h1>` per page.
- Honours `prefers-reduced-motion`.
